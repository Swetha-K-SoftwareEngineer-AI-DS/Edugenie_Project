    About EduGenie

    Full-Stack Educational AI Assistant for Student Learning

    🌟 Project Overview

    EduGenie is an educational platform designed to empower learners of all academic stages. It integrates state-of-the-art Generative AI with a structured database backend to deliver reliable, student-friendly learning experiences.

    FastAPI Python 3 Google Gemini MySQL SQLAlchemy HTML5 / CSS3 / Vanilla JS

    🔒 Security & Best Practices

    • Safe API Integration: Gemini API keys are loaded strictly via backend environment variables; never exposed to client-side code.
    • Database Protection: Parameterized SQLAlchemy ORM operations prevent SQL injection.
    • XSS Mitigation: User-supplied input is sanitized and HTML-escaped before insertion into the DOM.
    • Rate Limiting: SlowAPI protection defends against automated denial-of-service and API abuse.
    • Input Validation: Strict Pydantic models validate all incoming payload schemas.
